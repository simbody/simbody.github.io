647 // There is no conventional meaning for normalize() applied to a matrix. We
648 // choose to define it as follows:
649 // If the elements of this Mat are scalars, the result is what you get by
650 // dividing each element by the Frobenius norm() calculated above. If the elements are
651 // *not* scalars, then the elements are *separately* normalized. That means
652 // you will get a different answer from Mat<2,2,Mat33>::normalize() than you
653 // would from a Mat<6,6>::normalize() containing the same scalars.
654 //
655 // Normalize returns a matrix of the same dimension but in new, packed storage
656 // and with a return type that does not include negator<> even if the original
657 // Mat<> does, because we can eliminate the negation here almost for free.
658 // But we can't standardize (change conjugate to complex) for free, so we'll retain
659 // conjugates if there are any.

661 if (CNT<E>::IsScalar) {
662 return castAwayNegatorIfAny() / (int(SignInterpretation)*norm());
663 } else {
664 TNormalize elementwiseNormalized;
665 // punt to the column Vec to deal with the elements
666 for (int j=0; j<N; ++j)
667 elementwiseNormalized(j) = (*this)(j).normalize();
668 return elementwiseNormalized;
669 }
670 }
