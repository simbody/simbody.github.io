Detailed Description

Three mobilities – coordinated rotation and translation along the surface of an ellipsoid fixed to the parent (inboard) body.

The generalized coordinates q are the same as for a Ball (Orientation) mobilizer, that is, a quaternion or an x-y-z body-fixed Euler sequence depending on the "use Euler angles" modeling option. The three generalized speeds u for this mobilizer are also the same as for a Ball mobilizer, that is the three measure numbers of the angular velocity vector w_FM (unless the mobilizer is mirrored, see Mirroring below), the relative angular velocity of the outboard M frame in the inboard F frame, expressed in the F frame. That is unchanged by setting the "use Euler angles" modeling option. Note that qdot != u for this mobilizer.

Mirroring

This mobilizer can optionally be mirrored about the plane normal to one of the axes of the inboard frame F, which is useful for building a left/right pair of joints (e.g., a pair of shoulders) that are driven by the same coordinates.

We define S as the reflection that reverses an axis k, that is, s[k] = -1 and s[i] = 1 otherwise. For example, if mirroring about the Y-axis then s = [1 -1 1] and S = diag(s):

        [ 1  0  0 ]
    S = [ 0 -1  0 ]
        [ 0  0  1 ]

Mirroring about F's axis k replaces the cross-mobilizer position p_FM with S*p_FM and the cross mobilizer rotation R_FM with S*R_FM*S. Therefore, the mirrored cross-mobilizer transform is defined as:

                    [              |        ]
    X_FM_mirrored = [   S*R_FM*S   | S*p_FM ]
                    [..............|........]
                    [ 0    0    0      1    ]

The generalized coordinates parameterize an unmirrored rotation, and the generalized speeds are the angular velocity of the unmirrored joint, so that N(q) and thus qdot=N(q)*u are the same for a mirrored mobilizer as for an unmirrored one. In exchange, this means that u is no longer equal to w_FM for a mirrored mobilizer, but rather:

    w_FM = -S u

In general, angular quantities are mirrored via w' = -S*w and linear quantities via v' = S*v. Therefore the hinge matrix H_FM and its time derivative HDot_FM can be mirrored via the following operations:

    H_FM_mirrored    = diag(-S,S)*H_FM
    HDot_FM_mirrored = diag(-S,S)*HDot_FM

where diag(-S,S) is a 6x6 block diagonal sign matrix:

                 [ -S   0 ]    -S mirrors the angular (w_FM) rows
    diag(-S,S) = [        ]
                 [  0   S ]     S mirrors the linear (v_FM) rows

Mirroring about F's Z-axis

Note that when mirroring about F's Z-Axis, the normal vector Mz flips and points into the ellipsoid. Therefore, the position of M in F depends on a negated Mz vector:

    p_FM = -diag(a,b,c)*Mz

All internal calculations, including mobilizer equations and fitting methods, account for this negation. However, keep in mind that, if reading off the ellipsoid outward surface normal (e.g., getMobilizerTransform().R().z()), you will need to account for this negation.

Parameters

g_radii = -------------- = ~Jr --------------
          partial(radii)        partial(p_GB)

This operator may be useful when computing gradients with respect to this mobilizer's radii when optimizing the geometry of a multibody system.
