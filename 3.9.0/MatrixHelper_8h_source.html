129 // External "View" constructors //
131
132 // These constructors produce a matrix which provides a view of externally-allocated
133 // data, which is known to have the given MatrixCharacter. There is also provision
134 // for a "spacing" parameter which defines gaps in the supplied data, although
135 // the interpretation of that parameter depends on the MatrixCharacter (typically
136 // it is the leading dimension for a matrix or the stride for a vector). Note
137 // that spacing is interpreted as "number of scalars between adjacent elements"
138 // which has the usual Lapack interpretation if the elements are scalars but
139 // can be used for C++ vs. Simmatrix packing differences for composite elements.
140 // The resulting handle is *not* the owner of the data, so destruction of the
141 // handle does not delete the data.
142
143 // Create a read-only view into existing data.
144 MatrixHelper(int esz, int cppEsz, const MatrixCommitment&,
145 const MatrixCharacter&, int spacing, const S* data);
146 // Create a writable view into existing data.
147 MatrixHelper(int esz, int cppEsz, const MatrixCommitment&,
148 const MatrixCharacter&, int spacing, S* data);

188 // "Copy" an existing MatrixHelper by making a new view into the same data.

198 // Copy assignment //
200
201 // Behavior of copy assignment depends on whether "this" is an owner or view. If
202 // it's an owner it is resized and ends up a new, dense copy of "source" just as
203 // for the DeepCopy constructor above. If "this" is a writable view, sizes must match
204 // and we copy elements from "source" to corresponding elements of "this". If
205 // "this" is not writable then the operation will fail.
206 MatrixHelper& copyAssign(const MatrixHelper& source);
207
208 // Same as copyAssign() except the source has element types which are logically
209 // negated from the element types of "this". Since the result must have the
210 // same value as the source, this requires that all the copied elements are
211 // actually negated at a cost of one flop per scalar.
212 MatrixHelper& negatedCopyAssign(const MatrixHelper<typename CNT<S>::TNeg>&);
213
215 // View assignment //
217

221 // writability is inherited from the source.

223 MatrixHelper& writableViewAssign(MatrixHelper& source);
